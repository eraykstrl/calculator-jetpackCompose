
# MyComposeApp

This project is developed entirely using **Jetpack Compose** for Android.  
All UI elements are built with Compose, no XML layouts are used.

## Features
- Fully built with Jetpack Compose
- Modern and reactive UI
- Simple navigation between screens
- Designed for Android devices

## Installation
1. Open Android Studio
2. Import this project
3. Run on an emulator or a real device
